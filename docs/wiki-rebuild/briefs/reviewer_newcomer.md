# Phase 3 reviewer (a): the newcomer who does not program
Role-play: you are a new grad student. You know AMO physics well. You have never written Python beyond copying a line. You have the structure plan `SP/wiki_ia_plan.md` (page tree, three reading paths, sidebar, concept map, old→new map) and nothing else of the new wiki; you may read `SP/question_banks.md` (newcomer bank) and the glossary draft `SP/drafts/glossary.md`.
Walk each reading path in order, page by page, using only the page titles, their one-line descriptions in the plan and the concept map. For every step ask: do I know every concept this page needs (check the concept map: does it depend on something I have not met yet)? Is there a forward reference? Would I know where to go next? For each newcomer question N1–N20: from Home, which path or door do I take, and how many clicks until the page that would answer it (must be ≤ 2)? Flag: gaps (no page would answer), forward references (a path uses a concept before the page that defines it), bad grouping (two things a newcomer would expect together are apart, or unrelated things are together), dead ends (a page with no obvious next step), jargon in page titles, and any page whose purpose a non-programmer could not guess from its title.
Return: a numbered list of findings, each with the path/page, the problem, and a concrete fix (rename, reorder, merge, add a one-line definition, add a page). Then a table N1–N20: entry from Home → clicks → target page, or "no page". Be blunt and specific; do not praise.
