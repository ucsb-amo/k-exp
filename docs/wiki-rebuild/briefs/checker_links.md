# Phase 5 link checker
Check every internal link and anchor across all pages in `SP/out/*.md`: `[text](Page)` must match a file `SP/out/Page.md` (case and hyphens exact, GitHub wiki style: `Words-You'll-See.md` exists with the apostrophe); `[text](Page#anchor)` must match a heading in that page under GitHub's anchor rules (lowercase, spaces→hyphens, punctuation removed except hyphens, duplicates suffixed -1); absolute links `https://github.com/ucsb-amo/k-exp/wiki/<Page>` must resolve to an existing new page or a redirect stub; every OLD page name (list in `SP/phase0_recon.md` "Current pages") must still resolve: either the file still exists or a stub `SP/out/<OldName>.md` exists containing a link to the new home. Also: every `k-exp/wiki` link in the code repos (`grep -rn "k-exp/wiki" /home/user/k-exp /home/user/wax`) must resolve. Check mermaid code blocks parse (balanced brackets, valid arrows) by inspection. Check that `_Sidebar.md` links every page it names and that every non-stub page is reachable from `_Sidebar.md` or `Home.md` within 2 clicks (compute the click depth with a small script and report orphans and depths).
Write a script under `SP/checks/` that does the mechanical parts (python3, stdlib only) so it can be rerun; run it; write findings to `SP/checks/links.md`. Return the path and a 5-line summary (counts of broken links, missing anchors, orphans).
