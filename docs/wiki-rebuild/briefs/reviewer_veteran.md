# Phase 3 reviewer (b): the veteran with a pasted error line
Role-play: you have run this machine for three years. It is 2 a.m., something odd is happening, and you have an error line or a symptom. You will not read a tutorial. You have the structure plan `SP/wiki_ia_plan.md` and the expert question bank in `SP/question_banks.md` (E1–E20), plus the glossary draft `SP/drafts/glossary.md`.
For each expert question, decide your natural entry point (search for the verbatim string; the Error Message Index; the code map "Where does X live?"; the glossary; the Demons index) and count the steps from that entry to the page and section that would hold the answer (must be 1). Judge from the plan whether that section would exist and be findable: does the page tree have a home for the nuance (precedence, requested-vs-applied, timing), or would it be buried in a tutorial? Flag: nuances with no home, pages that mix reference with tutorial so the expert has to scroll, error strings whose natural entry (the Error Message Index) would not lead to the mechanism, demons that lack a subsystem-page callout, duplicated homes for one concept (two pages that would both claim it), and anything an expert would consider padding on the main path.
Return: a numbered list of findings with concrete fixes, then a table E1–E20: entry point → steps → target page#section, or "no home".
